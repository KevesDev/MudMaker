## Phase deliverables and exact handoff
Each phase below is a **small stand-alone vertical slice**. One Builder, then one independently scoped Auditor, with a real hands-on demonstration or runnable harness **before** checkoff. Usually more than one phase should be finishable within a single Claude usage window; if unexpectedly broad, Lead splits the phase in the central tracker *before* assigning it.

**S08.1 Frame admission** — Deliver: TLS/Origin/handshake and message caps. User test: Valid/oversize client connections. Auditor negative case: No resource preauth flood.

**S08.2 Session identity** — Deliver: Authenticate actor and expiry. User test: Two separate clients connect. Auditor negative case: No actor spoof.

**S08.3 Typed decoding** — Deliver: Strict protocol and UTF-8 validation. User test: Command UI and text both work. Auditor negative case: Unknown kind/invalid enum rejected.

**S08.4 Short posts** — Deliver: Explicit SubmitText routing. User test: Post "hi" as RP. Auditor negative case: Never becomes command.

**S08.5 Long posts** — Deliver: Multiline RP with emoji. User test: Save long RP draft. Auditor negative case: No embedded commands.

**S08.6 Descriptions** — Deliver: Authorized persistent bio revision. User test: Edit and reopen description. Auditor negative case: No stale overwrite.

**S08.7 Long commands** — Deliver: Per-command typed long arguments. User test: Run long builder action. Auditor negative case: Never becomes RP.

**S08.8 Rate limits** — Deliver: Principal/action/byte budgets. User test: Flooder cannot starve player. Auditor negative case: Bounded CPU and memory.

**S08.9 Backpressure** — Deliver: Session/world/output queue caps. User test: Slow reader gets resync. Auditor negative case: No accepted work silently lost.

**S08.10 Safe output** — Deliver: GUI/terminal/log encoding. User test: Display HTML and ANSI literal. Auditor negative case: No XSS/control/log injection.

**S08.11 Visibility** — Deliver: Per-actor audience filtering. User test: Hidden Joe invisible to Pat. Auditor negative case: No guessable target.

**S08.12 Reconnect** — Deliver: Resumable receipt and dedupe. User test: Retry post after disconnect. Auditor negative case: No duplicate post.

## Remote ingress acceptance specifics
- Explicit protobuf discriminator separates `CommandText`, `InvokeAction`, `SubmitText`. One-word RP content stays a post; a long privileged command stays a command under its registered grammar. Input **size determines safety budget, never semantic kind**.
- Default **limits and rate classes** are in `contracts/input/v1/default-policy.json`. Those are initial choices to **measure**, not promises of DDoS immunity. Reject oversize before allocating decode data, with bounded queues/worker fanout and structured errors.
- Auth/session from server; TLS/Origin when applicable, strict UTF-8, per-message ownership; output-context encoding. Reject player source/assemblies/graphs. File uploads are **not** within these typed message kinds.
- Execute bad-origin, malformed payload, long text, flooder/normal user, slow reader and reconnect cases from indexed matrix. Browser vs native client handshake differences are handled at transport adapter without bypassing action policy. Source evidence is in [research crosswalk](../../03-contracts/client-input-v1/08-evennia-research-crosswalk.md) and [security ops](../../03-contracts/client-input-v1/07-abuse-security-operations.md); **no agent web research**.

## Client/server boundary and S09C dependency
S08 builds the **safe native MudMaker network gateway**, not the generic third-party Player Client UI. `CommandText/InvokeAction/SubmitText` continue to be authenticated typed messages and never classified by length. The separate [S09C](S09C.md) uses S08's native adapter for MudMaker games and a bounded Telnet/TLS adapter for unrelated MUDs. S08 and S09C share protocol/error test fixtures but **must not share client UI intent handlers with the server CommandService**. [Workspace ownership](../../03-contracts/ui-ux/01-workspaces-and-ownership.md), [Player Client](../../03-contracts/ui-ux/05-player-client-workspace.md). No UX client tab implementation is required to finish S08 network internals.
