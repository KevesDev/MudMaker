## S02.3i Text-art renderer (this dispatch)
**Write scope:** `app/src/art/**` (new), `app/src/theme/**` plus `contracts/ui/v1/theme-defaults.v1.json`, `docs/03-contracts/ui-ux/theme-presets.md`, `docs/03-contracts/editor-theme-manager.md` (art role tokens only, S02.1 process), `app/vite.config.ts` and `tsconfig` only if needed for `?raw` art files, and `app/src/home/useNarrowFlag.ts` (carry-over cleanup below). No scene, no icons, no splash changes.
- **Data format:** a plain text file per piece: header lines (`name`, `legend` mapping one character to a role or `.` for transparent) then the pixel grid, one character per pixel, rows of equal length. Two pixel rows make one character row, so height is even. The parser validates rectangularity, even height, legend completeness, unknown characters and unknown roles, with errors naming piece, row and column (typed errors, never silent). Roles are the single list defined in the theme schema (read from it, not retyped).
- **Roles and tokens:** add `color.art.<role>` tokens for these roles: `deep`, `sky`, `haze`, `far`, `mid`, `near`, `accent`, `glow`, `star`, `light`. Both presets define all of them, built only from the owner's palette values plus documented derivations under the S02.1 rules (record source color, direction and amount in theme-presets.md, and keep derivation and document tests green). Mapping intent (from the mockup's colors): Neon Lights deep Vulcan, sky Persian Blue, haze American Purple, far and mid Electric Navy steps, near a dark Persian Blue/Vulcan step, accent Intense Hot Pink, glow Digital Mint, star and light mint tints; Neon Dark Mode deep Void, sky and haze Dark Graphite and Electric Purple steps, far and mid purple steps, near Void, accent Electric Purple, glow Neon Cyan, star and light cyan tints. Neon Lime is not used in art. Art colors are decorative (no text contrast floor) but must be distinguishable from each other and never reduce text contrast (the clear zone in S02.3k handles that).
- **Renderer:** a React `TextArt` component taking a parsed piece. Each text cell shows two pixels with the upper half block, foreground the upper pixel's role and background the lower pixel's role (`█` when equal, `▄` when only the lower is opaque, `▀` when only the upper is, a space when both transparent). Adjacent cells with identical character, foreground and background merge into one span (run-length). Colors come from CSS classes per role that reference the art tokens (one stylesheet, role list verified against the schema by a drift test); no inline color values, no literals. The output is `aria-hidden`, not focusable, `user-select: none`, `pointer-events: none`, monospace token font with a line height of exactly one cell, whole cells only, never blurred.
- **Determinism and cost:** parse once per piece (memoized), output depends only on the piece and theme; a sample piece shows run merging reduces spans well below the cell count; no DOM scans, no per-frame work.
- **Tests (real fixtures, can fail):** parser rejects each malformed case with the exact location; renderer produces the exact characters and classes for a hand-computed small piece; run-length merge; transparent handling; every role has a class and a token in every preset and every scope that needs it; changing the preset changes the resolved colors with the same DOM; `aria-hidden` and not focusable; no color literals in art code (the existing colorLiterals scan stays green); and jsdom limits stated (glyph joining and real colors).
- **Carry-over cleanup (from the S02.3h audit):** remove the redundant `row.dataset.narrow` write in `useNarrowFlag.ts` (React already renders it), keeping tests green.

## S02.3k Landscape scene (after j)
Fantasy landscape traced from the mockup (castle on a cliff with a viaduct at the left, layered mountains with pines and a moon at the right, a lake with reflections along the bottom, sparse stars) as layered pieces anchored to the window edges (sky and star scatter generated from a fixed seed to fill any size), built from the mockup by converting its art regions to role grids with a throwaway script (text and buttons in the mockup are masked out), a clear zone behind the wordmark, actions and footer so every text color keeps its contrast over whatever lies beneath (computed from the real rendered cell colors), decorative only, no animation. Owner reviews the full splash against the mockup.
