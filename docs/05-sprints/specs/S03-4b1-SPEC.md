## Binding review and decisions

Read this spec, S03-3-SPEC.md, S03-2-SPEC.md and engine-control-v1.md; use cached ADR002/003/005, ecs-core and system-boundaries decisions. Existing World is the sole mutation gateway; immutable registry is the sole schema authority; existing codec owns descriptor-driven FieldId/value mapping. New read access must preserve those owners. ADR008 remote protocols and ADR015 game templates remain OPEN and untouched. No production bootstrap chosen in this slice.

1. **Owned live pages:** add World read API taking explicit offset and positive limit, returning independent EntityIds, total at this call and optional next offset. Reuse the existing authoritative WorldState::live sequence, copying at most limit IDs with checked bounds; no repeatedly copying an ever-larger prefix, scanning all entities, mirror collection or fixed population cap. Builder confirmed this sequence is owned/repaired by World, so no identity API change/helper is needed. Respect existing writer-thread checks and typed resource errors. Offset at/beyond end returns empty terminal page; zero limit is a typed argument failure. Existing inspect_live(limit) remains compatible, including its existing zero behavior.
2. **Consistency boundary:** pages enumerate an unchanged world completely without omissions/duplicates. These are live diagnostic pages, not a frozen snapshot: create/destroy between calls may reorder the existing dense sequence, so callers refresh/restart when they mutate. Full world/index/generation identity is always preserved; inspecting a stale entry must be rejected by the existing gateway. No new mutation revision/counter, snapshot cache, replay or replication promise. Future query/replication contracts own stronger consistency. Single paired control requests later run sequentially on the sole writer.
3. **Owned catalog pages:** add bounded registry read API with offset, positive limit, total and next offset, returning existing immutable owning handles after freeze. Define order as successful publication order, stable after freeze. Keep an index of existing handles inside the same registry only if needed; no copied schema definitions, external catalog manager or second validator. Integrate that derived index failure-atomically with existing publication. Reject before freeze and zero limit; past-end is terminal. No allocation/whole-catalog sorting or definition cloning per page; retain metadata/FieldIds/defaults unchanged and distinguish absent default from explicit Null.
4. **Reuse conversion:** expose descriptor-driven component-root and standalone field/value conversions through the existing wire codec owner, delegating to its existing mapping/validation/budget machinery. Inputs use actual immutable ComponentSchema/ValueSchema metadata; outputs are owned native values or protobuf values with existing typed errors. Provide shared aggregate-budget handling for multiple sibling values/components in one message; do not reset aggregate value-node accounting per sibling; preserve existing per-text length and current recursive-depth guards (no invented cumulative text/depth cap), invent an EntityRef to invoke inspection conversion, duplicate converters or expose mutable codec internals. Existing inspection adapters must use the same implementation. Schema constraints/default normalization/live references remain registry/World responsibilities; wire representation checks remain codec responsibilities.
