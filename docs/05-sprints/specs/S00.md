# S00 — Documentation and owner decisions (no fake user tests)

**Status:** ACTIVE / document review. **Canonical phase status:** [S00 tracker](../../SPRINT-TRACKING.md#s00). **This sprint does not implement a UI, runtime or compiler.** Earlier S00 rows that asked someone to click around a nonexistent app were misapplied implementation policy and have been replaced by reviewable document acceptance gates.

## Actual purpose
Deliver a searchable, consistent, owner-approved contract set that Builders can implement from and Auditors can verify **without researching evennia/Mudlet/framework choices themselves**. S00 marks specs as drafted/in review; a phase is DONE only when an independent reviewer has checked its actual document gate and recorded that result in the tracker.

## Decided product model
**Launch → Loading → Splash** (MudMaker logo/name, exact installed version/build, visible Create/Play/Host, app health and safe recovery) → chosen workspace. Each workspace toolbar contains **Go To ▾** with Create/Play/Host/Splash. Unsent work and active network/hosting state are retained or explicitly confirmed: [authoritative navigation state machine](../../03-contracts/ui-ux/00-launch-and-workspace-navigation.md).

A single **HostSupervisor** may host only one project at once. Leaving Host asks **Keep Hosting in Background / Stop Hosting & Switch / Cancel**, and never implicitly stops a running game. Users may edit **other** projects in Create and connect to **other** games in Play while hosting continues, and return to the same Host session. Client leaving active game similarly offers Keep Connected / Disconnect / Cancel; Create switching retains unsaved draft or saves after explicit confirmation. No navigation disposes running services.

## Evidence and status
Documentation review uses `source link + link/schema/consistency checks + independent reviewer signoff`; **NOT** "user clicks a UI" or "test host running" before software exists. Drafted contracts move to AUDIT. Only reviewer PASS with issues resolved moves the corresponding tracker row to DONE; S00 progress remains 0/4 until that happens. Research/ADRs still unresolved are recorded as **owner gates** for S01, not disguised as UI acceptance. S00 does not pretend C++/C# runtime or network is built.
