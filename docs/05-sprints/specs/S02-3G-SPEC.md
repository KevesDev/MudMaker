# S02.3g SPEC — Window frame

**Status:** APPROVED, IN PROGRESS. **Binding sources:** [17 splash art and window frame](../../03-contracts/ui-ux/17-splash-art-and-window-frame.md) (Window frame section), [10 shared language](../../03-contracts/ui-ux/10-visual-language-and-shared-shell.md) (unified toolbar), [15 wireframes](../../03-contracts/ui-ux/15-screen-wireframes-and-interaction-states.md), [16 microcopy](../../03-contracts/ui-ux/16-microcopy-and-density-acceptance.md), [02 interaction rules](../../03-contracts/ui-ux/02-interaction-state-and-accessibility.md) (Tooltip display rule, input ownership), the mockup in `docs/03-contracts/ui-ux/assets/`. Windows only.
**Predecessors:** S02.1 to S02.3f, S02.2g DONE.
**Write scope:** `app/src/frame/**` (new shared frame component), `app/src/home/**`, `app/src/App.tsx`, `app/src/ui/**` only for a primitive option, `app/src-tauri/**` (window commands, `tauri.conf.json`, capabilities with minimal permissions), `contracts/ui/v1/home-controls.v1.json`, `actions.v1.json`, `INDEX.md` and count/drift tests, `app/src/theme/**` plus `theme-defaults.v1.json`, `theme-presets.md`, `editor-theme-manager.md` only to add tokens (S02.1 process, both presets keep passing).
**Deliverable:** the application draws its own top row and the OS title bar is removed.
- `decorations: false`; one shared `AppFrame` row component: at the start the text `MudMaker` (the application mark arrives with the art slice), at the end minimize, maximize or restore, and close. The whole row except the controls is a drag region (Tauri drag region, with the minimal permission); double click on the row toggles maximize. A thin continuous border in the `color.border.frame` token surrounds the window. The row height, typography (monospace token), spacing and focus treatment come from tokens; it is built so Create, Play and Host toolbars (doc 10, 15) can place their content in the middle and Settings and Go To at the end later. The home screen uses the same component with empty middle.
- Window controls are catalog controls (new surface, e.g. `home.frame`, with full metadata and registered actions owned by one shell router): minimize, maximize or restore (label follows the real maximized state, read from the window), close. Close behaves exactly as Quit (the existing quit path and its future stop-hosting guard); there is one quit implementation, not two. Icon-only controls: accessible name and the tooltip rule (icon-only shows its name). Glyphs are plain text characters in the monospace font, no icon library, no images.
- Default window size and minimum window size come from named configuration in `tauri.conf.json` (default wide enough for the full splash, minimum sized so the narrow layout still works). Window state changes (maximized, restored) update the control label through the shell, not by guessing.
- Capabilities: an explicit minimal list, no `core:default`; grant only what is used (start dragging, minimize, toggle maximize, is-maximized and the existing commands); document each permission by name in the capability file comment or the report.
- Failure handling: if a window command fails, the control shows its error state and a diagnostic is logged with the launch id; nothing silent.
**Acceptance:** AC-01 no OS title bar; the frame row shows exactly `MudMaker` and three controls; AC-02 each control is a native button that activates once through the Input Manager and bus and calls its shell command (tests prove key presses are not intercepted and the native click runs once; the browser turning Enter or Space into that click is verified in the owner hands-on, jsdom cannot); maximize label toggles with the real window state; AC-03 drag region and double click behavior declared and tested at the DOM level, real dragging verified in the owner's hands-on; AC-04 close equals Quit via the single quit path; AC-05 tokens only, both presets pass contrast and literal scans, focus rings visible on the controls; AC-06 catalog and counts consistent, capabilities minimal, no new dependencies; AC-07 Rust tests for any new command logic; filtered vitest, build, cargo test.
**Verification:** `npx vitest run src/frame src/home src/ui src/theme src/App.test.tsx src/appInfo.test.ts`, `npm --prefix app run build`, `cargo test --manifest-path app/src-tauri/Cargo.toml`. Auditor verdict for the slice. Owner hands-on is combined with S02.3h and S02.3i (the splash is shown once it matches the mockup).
