## Deliverable (the splash content region, below the frame row)
- **Wordmark:** the block-letter banner of `MudMaker` as data (rows of full and half block characters in a fixed monospace grid), rendered as text with `color.accent.primary` and a restrained dithered lower edge using shade characters, matching the mockup's pixel lettering. The banner is `aria-hidden`; the real h1 text `MudMaker` is present for assistive technology. Version and build (from the shell, once) hang small at the banner's LOWER right overhanging outside it, version on the first line and build on the next, as in the mockup; the banner stays centered on the splash axis and is not resized by the version. Sizing in whole character cells from tokens (add a wordmark size token only if needed), scaling with the window by whole steps, never blurred.
- **Divider and tagline:** a thin line of line characters with a small center four-point star glyph in `color.accent.tertiary`, then the single brand line `The Ultimate MUD Suite` letter-spaced in `color.text.secondary` (stored once as a string; owner-approved from the mockup, removable by deleting it).
- **Action row:** Create, Play, Host as equal-width, equal-height controls in one row, compact gap from spacing tokens, thin border; Create in `color.accent.primary`, Play as a filled `color.accent.secondary` button with primary-mint text, Host in `color.accent.tertiary`; label in the monospace token style, followed by a chevron glyph character; these are the catalog controls themselves (Button), activated through the Input Manager as today. The refused-activation sentence behavior from earlier slices is unchanged. Below the narrow breakpoint token the row stacks vertically at full width.
- **Footer:** below a second thin divider with the same star ornament, `Settings` and `Quit` as small text actions separated by a thin vertical rule, text only. Settings opens the existing menu with Appearance.
- **Conditional lines:** `Active World: {name}` only while hosting (absent now; render path exists only if a real host source exists, otherwise not built); Recent Projects and Recent Worlds links per doc 17 only when their lists exist (not built now).
- **States:** loading shows the wordmark and the short progress indicator only; failure and damaged-install keep the wordmark, divider and tagline composition and replace only the action row with the one failure line and Retry (existing behavior); damaged install keeps its one line.
- **Layout and density:** the content block is centered horizontally and sits slightly above the vertical center of the area below the frame; vertical gaps between wordmark, divider, tagline, action row, divider and footer use the small spacing tokens (doc 10 and 16: no large gutters, no cards, no nested boxes); content width follows the window up to a token maximum; no horizontal scroll down to the minimum window size; text scale 200 percent keeps every action reachable.
- **Typography and color:** monospace family token everywhere in the splash; sizes from tokens (add display size tokens only through the S02.1 process); all colors from tokens; the empty space and background stay the plain canvas surface until the art slice.
- **Text inventory** of the default state is exactly: the frame row text, wordmark (banner plus h1), version and build, the tagline, Create, Play, Host, Settings, Quit. Nothing else.
