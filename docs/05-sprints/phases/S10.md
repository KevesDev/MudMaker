## Phase handoff / sign-off
For **each** checkbox: Lead writes exact scoped task + accepted contract and test path; assign one Builder to implement, produce focused test output and a usable demonstrator; assign one different Auditor to independently inspect that phase's delta and negative tests; show user the demo as soon as runnable; record feedback/fixes in the same phase and repeat focused audit only for changed code. Lead then commits the verified phase, adds specific evidence link beside the checkbox, and updates progress count in [SPRINT-TRACKING](../../SPRINT-TRACKING.md). **No next phase is marked complete early**, even if another phase has source files. A real blocker remains unmarked until resolved. Builder doesn't run full suite unless specifically authorized under agent governance.
