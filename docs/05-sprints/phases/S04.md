Lead then commits the verified phase, adds specific evidence link beside the checkbox, and updates progress count in [SPRINT-TRACKING](../../SPRINT-TRACKING.md). **No next phase is marked complete early**, even if another phase has source files. A real blocker remains unmarked until resolved. Builder doesn't run full suite unless specifically authorized under agent governance.
