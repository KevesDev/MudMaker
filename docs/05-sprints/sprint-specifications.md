# Legacy sprint overview — superseded

The current, definitive [MudMaker Sprint Tracker](../SPRINT-TRACKING.md) contains **118 small phases** with deliverables, user-testable checks, scoped Auditor requirements, progress and evidence. The **one spec per sprint** set lives in [specs/INDEX.md](specs/INDEX.md). Read only the active sprint's spec and referenced technical contracts; do not use older broad sprint-plan prose as an alternative task list.

Research and architecture selection belong to the project owner/documentation stage, **not** Builder/Auditor tasks. When a prerequisite is missing, mark BLOCKED in the tracker.
