# 05 | Code + Graph Authoring and Runtime Acceptance Matrix

**Status:** binding test matrix, tests required before scripting is declared complete. **Owner:** independent Auditor + UI stakeholder. **Agent cost:** scoped tests, final full suite only Auditor on Lead authorization.

## Code editor
CODE-01 create versioned script from entity and project tree; same asset reused, no duplicate inline source. CODE-02 real compile failures produce accurate line/diagnostics, never "success" on noop. CODE-03 autocomplete/API docs and allowlisted function permissions; role-specific denied API isn't accessible at runtime. CODE-04 exported typed variable has default+instance override+persisted migration; invalid value rejects. CODE-05 script function exposed as graph node has correct typed ports and signature-update dependency diagnostics. CODE-06 script Test runs real ECS mutation and observed messages; debugger trace maps source and world revision. CODE-07 tablet remotely edits/validates and focus/keyboard works without local engine compiler.

## Visual graph editor
GRAPH-01 searchable typed palette by graph kind, including registered code function, disabled choices show reason. GRAPH-02 mouse/touch keyboard add/connect/rewire/delete/undo/redo, pan/zoom, no hover-only essential control. GRAPH-03 port mismatch, invalid cycles, missing script ref fail validation/publish with precise error. GRAPH-04 node graph save/reload retains semantic state and layout separately, executes real server plan. GRAPH-05 isolated debug shows actual path, typed values, effect plan and per-observer narration; no simulated positive screenshot. GRAPH-06 large graph responsive on target tablet/desktop with measured budgets. GRAPH-07 visually meets approved design reference, contrast, screen reader and tooltips on focus/tap.

## Runtime and engine bridge
RUN-01 same actor/world inputs to code and equivalent graph yield same validated ECS mutation/events. RUN-02 script returns typed effect; no direct pointer/DB or global mutable authority, stale entity handle rejects. RUN-03 hook before/after/replace/both, world event start/stop and multiple-choice quest stage retain exactly-once effects. RUN-04 private different-world instances, quests and NPC visibility cannot leak across script capabilities. RUN-05 script worker infinite loop/memory bomb/crash denied/terminated without crashing live engine. RUN-06 save draft != live update; publish deploy compatibility checked, rollback restores known good. RUN-07 headless Linux + optional desktop host load identical release; tablet client sees output without native compiler. RUN-08 world restart retains persistent variables/quest progress/graph bindings, not local script temporary state. RUN-09 untrusted malicious script cannot use file/process/network/unsafe native host calls or forge player ID. RUN-10 native C++ sanitizer/race tests and structured boundary-fuzz evidence, not mocked safety guarantees.

## Specific scenario
NPC Bob has a Code Script which checks a verified actor quest, shows a 3-answer quiz via typed dialogue, grants one reward for name prefix A, optionally begins a festival world event. A visual graph invokes one exposed function from the same script. Two real players are in room with different quest phases: only allowed player interacts/receives messages; wrong answer has correct nonprogression. On restart, neither the reward nor event duplicates. Commit sequence and effect plan visible in creator Event Trace.

## Verdict
Audit fails on any unimplemented promised behavior, fake context-load test as feature evidence, direct ECS mutation shortcut, isolated UI-only result, unsafe memory ownership, missing real device UX verification, or unresolved security critical. No permission to ship a toy partial engine marked complete.
